Recuperação_brinquedos

Um sistema bem simples em PHP pra cadastrar brinquedos e controlar o estoque. Dá pra adicionar, ver a lista, editar e apagar.

Como rodar 1- Liga o Apache e o MySQL no XAMPP 2- Joga a pasta do projeto dentro do htdocs 3- Cria o banco rodando o SQL do projeto no phpMyAdmin 4- Abrehttp://localhost/Ramon_trindade_2026/Recupera-o/ no navegador.
